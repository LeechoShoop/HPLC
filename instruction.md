# Руководство пользователя Lab Data Parser

Lab Data Parser — это быстрый нативный инструмент для чтения, анализа и визуализации лабораторных данных хроматографии (ВЭЖХ / HPLC) и масс-спектрометрии (mzML). Проект написан на Rust и предоставляет удобный графический интерфейс без внешних зависимостей.

## Основные возможности

- **Чтение форматов:** Поддержка HPLC CSV/TXT и mzML/mzXML.
- **Поиск пиков:** Настраиваемый алгоритм автоматического поиска пиков (настройка порога высоты и минимальной ширины).
- **Интерактивный GUI:** Визуализация хроматограмм, масштабирование, отображение времени удерживания при наведении.
- **Таблица пиков:** Сортировка и ручное добавление/редактирование названий пиков.
- **Экспорт:** Сохранение обработанных данных в форматах CSV, JSON, XLSX, а также экспорт графика в PNG.

## Запуск и сборка проекта

Для работы с исходным кодом вам потребуется установленный [Rust](https://www.rust-lang.org/).

### Сборка релизной версии GUI
Чтобы собрать приложение в виде одного исполняемого файла, готового для передачи коллегам в лабораторию (со всеми максимальными оптимизациями), выполните:

```bash
cargo build --release -p lab-data-parser-gui
```
Скомпилированный файл (например, `lab-data-parser-gui.exe` для Windows) появится в папке `target/release/`. Его можно скопировать и запускать на других компьютерах без установки дополнительных программ.

### Запуск GUI для работы
Чтобы запустить приложение напрямую, используйте команду:
```bash
cargo run --release -p lab-data-parser-gui
```

## Как пользоваться программой (Инструкция)

1. **Открытие файла:** В левой панели (Settings) нажмите кнопку **«Open file...»** (или выберите `File -> Open` в верхнем меню) и выберите ваш файл с данными. Программа автоматически определит формат по расширению.
2. **Визуализация:** Построенный график появится в центре экрана. Вы можете перетаскивать его мышкой и изменять масштаб колесиком. При наведении курсора на маркеры будут показаны точные значения времени удерживания (Retention Time).
3. **Поиск пиков:** В левой панели используйте ползунки **«Peak threshold»** (Порог пика) и **«Min peak width»** (Минимальная ширина). Поиск пиков и график будут пересчитываться автоматически (в реальном времени).
4. **Таблица пиков:** В нижней части экрана находится таблица всех найденных пиков.
   - Вы можете **сортировать** данные по любому столбцу, просто кликнув на его заголовок (например, по площади или высоте).
   - Вы можете **называть пики** вручную, кликнув в ячейку в столбце «Name» и введя текст. Название также обновится на графике.
5. **Экспорт:** После разметки данных вы можете выгрузить результаты:
   - В левом меню нажмите на соответствующую кнопку (JSON, CSV, XLSX, PNG).
   - Либо воспользуйтесь меню `File -> Export -> ...`.
   - График в виде PNG сохраняется со всеми пиками и вашими подписями.
